# Alcohol Consumption in the USA (1850 - 2013)

## Deskripsi
Repository ini berisi data tentang konsumsi alkohol di Amerika Serikat dari tahun 1850 hingga 2013. Data ini mencakup konsumsi berbagai jenis minuman beralkohol, termasuk bir, anggur, dan spirit, serta total konsumsi semua jenis minuman beralkohol.

## Data
Data disimpan dalam format CSV dan mencakup kolom-kolom berikut:
- **Entity**: Nama negara (dalam hal ini, Amerika Serikat)
- **Year**: Tahun pengukuran
- **Beer (NIAAA)**: Konsumsi bir per kapita (dalam galon)
- **Wine (NIAAA)**: Konsumsi anggur per kapita (dalam galon)
- **Spirits (NIAAA)**: Konsumsi spirit per kapita (dalam galon)
- **All beverages (NIAAA)**: Total konsumsi semua jenis minuman beralkohol per kapita (dalam galon)
